# AstroCrash-Game

This game was designed to run on Spyder IDE.

This is a 2D arcade-style game, where you play as a space ship, shooting asteroids to gain points, and avoiding asteroids to preserve your lives, of which you have 3.
It works based on locating cursor position and moving the ship to that point, as well as reading keyboard inputs.

**Controls:**
- Q/E to rotate pointing direction
- Left-click to shoot
- Move cursor to avoid asteroids
- R to restart after game over
